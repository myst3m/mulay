# 057 — 再起動をまたぐ値は店ごとに 1 ファイルへ全部書き直し、一時ファイルは毎回別の名前を O_EXCL で作る

状態: **採用** (2026-09-30 8d15968。一時ファイルの名前は 2026-10-04 90bfe08)

## 決定
- 対象は ObjectStore の persistent の店 (既定の店を含む) と VM の PERSISTENT のキュー。
- 置き場所: `<mulay.work.dir (既定 ".mulay")>/<アプリの名前>/<種類>/<名前>`。名前のうちファイル名に使えない文字は `_` にする。
- 1 つのファイルに 1 つの店 (キュー) の中身を全部書き、変わるたびに書き直す。
- 形: 1 行が 1 件。欄を空白で区切り、どの欄も base64。TypedValue は 3 つの欄 (種類、mime、中身) で、種類 `r` はバイト列のまま
  (中身はそのバイト列)、`v` は値 (中身は application/dw の writer の出力)。
- 書き方: 一時ファイル `<path>.tmp.<pid>.<n>` (n はプロセスの中の通し番号 `TMP-SEQ`) を O_EXCL で作ってから書き、名前を変える。
  失敗したら一時ファイルを消す。

## 理由
- 一時ファイルの名前が `<path>.tmp` に決まっていたとき、そこに置いた symlink の先を上書きでき、同じ店を同時に保存すると互いの
  一時ファイルを壊した (90bfe08)。毎回別の名前を O_EXCL で作れば symlink をたどらず、同時に保存しても最後に名前を変えたものが残る。

## 場所
- `mulay.rt.persist`: `dir`、`safe-name`、`tv-fields`、`tv-of`、`save`、`load`、`TMP-SEQ`

## 関連
- ADR 046 (ObjectStore と VM の永続の使い方)
